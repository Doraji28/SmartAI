# Soulrock - 최고의 음악들과 함께 즐기는 리듬게임

본 프로젝트는 **Love2D(LÖVE 11.5)** 엔진을 기반으로 개발된 2.5D 스캔라인 음악 동기화 리듬 액션 게임 **'Soulrock'**입니다. 
본 과제물은 **게임최적화기법(2A)** 기말 과제 평가 항목을 충족하도록 **AI 에이전트(Antigravity)**와의 페어 프로그래밍 협업을 통해 설계, 최적화 및 디버깅되었습니다.

---

## 1. 프로젝트 실행 방법

윈도우 환경에서 실행 패키지가 완벽하게 빌드되어 제공되므로, 별도의 의존성 설치 과정 없이 아래 방법으로 즉시 구동 및 테스트할 수 있습니다.

1. 프로젝트 루트 폴더에 위치한 **`run.bat`** 파일을 더블 클릭하여 실행합니다.
2. (콘솔 모드 및 테스트 구동 시) `love-11.5-win64/lovec.exe src` 명령어를 통해 실행할 수도 있습니다.

### 조작 단축키 (Key Bindings)
* **공통**:
  - `ESC`: 게임 종료
* **메인 타이틀 화면**:
  - `마우스 좌클릭` 또는 `임의의 키 입력`: 곡 선택 메뉴 진입
* **곡 선택 화면 (Stage Select Menu)**:
  - `방향키 [▲] / [▼]` 또는 `마우스 휠 스크롤`: 곡 목록 상하 이동 (Lerp 기반 스무스 스크롤 연동)
  - `방향키 [◀] / [▶]` 또는 `난이도 탭 클릭`: 게임 난이도 (**NORMAL**, **HARD**, **VERY HARD**) 실시간 변경
  - `[Enter]` / `[Space]` 또는 `상세 카드 클릭 / 곡 더블 클릭`: 선택한 곡 및 난이도로 연주 개시
* **인게임 플레이 (Gameplay)**:
  - `마우스 이동`: 2.5D 크로스헤어 실시간 조준
  - `마우스 좌클릭` / `[Z]` / `[X]`: 스캔라인이 노트와 겹치는 순간 입력 타이밍에 맞춰 판정 처리
    - *Beat / Breakable*: 1회 단발 타격 노트
    - *Drag*: 마우스 클릭 유지 상태로 스캔라인 지점을 브러싱해 터치하는 슬라이딩 노트
    - *Laser/Hold*: 스캔라인 주기에 맞춰 마우스를 꾹 누르고 있어야 하는 롱노트
* **결과 화면 (Victory / Defeat)**:
  - `[R]` 또는 `RETRY 버튼 클릭`: 현재 곡 및 난이도로 재시도
  - `[M]` 또는 `STAGE 버튼 클릭`: 곡 선택화면 메뉴로 회귀

## 2. 폴더 구조 (Directory Structure)

본 프로젝트는 평가 기준에 맞춰 아래와 같이 철저히 모듈화되어 있습니다.

```
Soulrock/
│
├── love-11.5-win64/       # Love2D 11.5 가상 윈도우 실행 파일 바이너리 패키지
├── src/                   # 게임 핵심 리소스 및 Lua 전체 소스코드
│   ├── Main/              # 메인 화면 그래픽 리소스
│   ├── Music/             # 11곡의 MP3 사운드 파일 및 전용 일러스트 앨범아트
│   ├── fft.lua            # 실시간 주파수 분석(FFT) 모듈 (최적화 완료)
│   ├── beat_manager.lua   # 싱크 비트 타임라인 및 난이도별 차트 빌더
│   ├── note.lua           # 3대 노트(Beat, Drag, Laser) 렌더러 및 입력 충돌부
│   ├── grid_renderer.lua  # 2.5D 터널 투사 렌더러 및 반응형 보스 시각 효과
│   ├── fx_manager.lua     # 카메라 셰이크, 대미지 플래시, 파티클 폭발 매니저
│   ├── ui_overlay.lua     # HUD 정보창, 네온 주파수 스펙트럼 렌더러, 결과 창 카드 UI
│   ├── sound_synth.lua    # 사운드 이중 로드 컨트롤러 및 인게임 SFX 신디사이저
│   ├── font_manager.lua   # 한글 나눔고딕 글꼴 관리 매니저
│   ├── conf.lua           # Love2D 가상 윈도우(1280x720) 하드웨어 환경설정
│   └── main.lua           # 게임 메인 루프 이벤트 핸들러
│
├── tests/                 # 품질 보증용 자동화 테스트 스위트
│   └── main.lua           # headless 콘솔용 자동화 단위 테스트 러너 (3개 항목)
│
├── docs/                  # 최종 학업용 제출 보고서
│   ├── development_log.md # 전체 리브랜딩 및 FFT 통합 개발 리포트
│   └── 이상혁2024391010_1일차~7일차.md # 학생 제출 양식 개발 일지
│
├── worklogs/              # AI 에이전트 협업 일지 (Day 1 ~ Day 9)
│   ├── day1.md ... day9.md # 일차별 프롬프트, 디버깅 과정 및 핵심 소스 코드 정리
│
├── run.bat                # 윈도우 원클릭 게임 구동용 배치 파일
├── audio_durations.txt    # 수록곡 하드웨어 타임라인 분석 데이터
└── README.md              # [본 파일] 프로젝트 종합 가이드북
```

## 3. 의존성 정보 (Dependencies)

- **런타임 엔진**: LÖVE 11.5 (Love2D)
- **런타임 언어**: Lua / LuaJIT (Love2D 내장 엔진 구동)
- **외부 종속성**: 추가로 로컬PC에 설치할 라이브러리나 런타임이 전혀 없습니다. `love-11.5-win64` 폴더 내에 윈도우 실행에 필요한 라이브러리(.dll) 및 파일이 이미 동봉되어 로컬 격리 환경에서 무설치로 완벽 구동됩니다.

## 5. AI 에이전트 협업 일지 요약

### 협업 파트너: Antigravity (Google DeepMind Advanced Agentic Coding)

본 리듬 액션 게임 개발에 있어 AI 에이전트를 조력자로 선정하여 코드 작성, 알고리즘 실시간 최적화, 그리고 오디오 지연 디버깅 분야에서 긴밀한 협업을 이끌어냈습니다.

1. **메모리 최적화 (Radix-2 FFT)**:
   - *문제*: 매 프레임 오디오 파형 256 샘플을 주파수 변환할 때 가비지 컬렉터(GC)에 과부하가 걸려 미세한 렉이 발생하는 최적화 병목 직면.
   - *협업*: 복소수 삼각함수 연산 테이블(`Twiddle Factor`) 및 비트 재정렬 인덱스를 사전 계산(`Pre-calculation`)하여 로딩 시점에 캐싱해 두고, 메모리 재할당 없이 기존 배열 내부에서 위치만 바꾸는 **In-place FFT 알고리즘**을 AI 에이전트의 피드백을 통해 완벽히 구축하여 60FPS 환경을 사수했습니다.
2. **동기화 지연 디버깅**:
   - *문제*: 오디오 시간 축 누적 연산 오차로 비트 주기가 뒤로 갈수록 맞지 않는 증상 발생.
   - *협업*: 프레임당 `dt` 누적 연산 방식을 철저히 탈피하여, 사운드 카드의 하드웨어 재생 스탬프인 `source:tell()` 기준 실시간 동적 보정 방식을 적용해 완벽한 칼박자 타이밍 동기화를 이끌어냈습니다.
3. **경계면 디버깅 및 예외 처리**:
   - *문제*: 롱노트 레이저 바가 스캔라인 상하 경계를 침범할 때 선이 반대로 뒤집히는 버그 및 완곡 직후 곡이 정지되면서 비트 카운터가 리셋되어 결과창으로 넘어가지 못하고 먹통이 되는 버그 발생.
   - *협업*: 경계면 한계 비트(`max_end_beat`) 절대수식 클램핑 및 오디오 정지 상태(`isPlaying = false`) 즉각 가로채기(Interrupt) 논리를 수립해 게임오버 루프를 철저히 검증해 냈습니다.
