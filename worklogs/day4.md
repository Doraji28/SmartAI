# [Day 4 Worklog] Cytus 방식의 스캔라인 판정 전환

## 1. 개발 목표
- 화면에 무작위로 뜨는 산만함을 줄이고 직관적인 조작감을 극대화하기 위해, 화면을 상하로 왕복 운동하는 스캔라인(Scanline)에 맞춰 겹치는 시점에 노트를 터치하는 Cytus 스타일의 판정 시스템으로 리리팩토링합니다.
- 클릭 전용 노트뿐만 아니라 드래그 슬라이딩 노트(Drag), 홀딩 노트(Laser/Hold)를 추가하여 리듬 게임 본연의 게임플레이 깊이를 제공합니다.

## 2. 핵심 구현 내용 및 세부 설계
- **삼각파 기반 등속 왕복 스캔라인 연출**: 경과 비트(Beat)에 따라 일정한 속도로 Y축을 오가는 스캔라인 공식(Y축 범위: 140 ~ 580)을 작성했습니다.
- **다양한 노트 메커니즘**:
  - **Beat/Breakable**: 스캔라인이 노트 중심을 스칠 때 타이밍 맞춰 클릭하는 노트.
  - **Drag Chain**: 마우스를 누른 채 라인과 겹치는 지점을 부드럽게 비벼 연속 처리하는 슬라이딩 노트.
  - **Laser/Hold**: 스캔라인이 도착하는 순간부터 끝나는 순간까지 연속으로 마우스 버튼을 유지해야 하는 레이저 바 형태의 홀드 노트.

## 3. AI 에이전트 협업 & 프롬프트 예시
- **프롬프트**: "스캔라인 Y가 140에서 580까지 등속으로 4비트 주기로 아래로 내려갔다가 다시 4비트 동안 위로 올라오게 등속 왕복운동(삼각파 모양) 연산 코드를 작성해줘. 아래로 이동할 때는 1, 위로 올라갈 때는 -1을 리턴해서 방향 표시기도 그리고 싶어."
- **협업 내용**: 에이전트는 주기 함수 분기를 설계하고 나머지 연산(`% 2.0`)을 적용하여 소수점 프레임 오차 없이 완벽한 대칭성을 지닌 왕복 Y 좌표 계산 수식을 제공했습니다.

## 4. 디버깅 및 검증 과정
- **문제점**: 레이저 노트를 꾹 누르고 있을 때 마우스 떼기 판정과 누르는 동안의 생명력(HP) 회복/피해 처리가 등속 시간(`dt`)에 비례하지 못하여 체력 게이지가 비정상적으로 소실되던 이슈가 발생했습니다.
- **해결 및 검증**: 레이저가 쥐어지는 프레임 간격에 맞춰 `love.update(dt)` 내부에서 `dt` 비례 HP 증감 공식을 설계하고, 실시간 마우스 입력 해제 감지 즉시 레이저 처리를 차단하고 상태 테이블에서 분리하여 안정적인 판정 루프를 검증했습니다.

## 5. 핵심 소스코드 블록 및 설명 (`beat_manager.lua` 발췌)
```lua
-- 경과 비트에 따라 스캔라인 Y 좌표를 삼각파 등속 왕복 형태로 계산하는 공식
function beat_manager.get_scanline_y(beat)
    local y_min = 140
    local y_max = 580
    local sweep_beats = 4.0 -- 편도 운동 비트
    local phase = (beat / sweep_beats) % 2.0
    
    if phase < 1.0 then
        -- 하강 운동 단계
        local progress = phase
        return y_min + progress * (y_max - y_min), 1 -- 1: Down
    else
        -- 상승 운동 단계
        local progress = phase - 1.0
        return y_max - progress * (y_max - y_min), -1 -- -1: Up
    end
end
```
