# [Day 1 Worklog] 2.5D 리듬 슈팅 액션 엔진 기초 구축

## 1. 개발 목표
- 1인칭 관점의 2.5D 공간에서 플레이어로 다가오는 입체 터널 그리드를 원근 투영법(Perspective Projection)을 통해 구현합니다.
- 조준선(Reticle) 및 크로스헤어를 마우스 입력과 실시간 매핑하여 보스 코어 및 쉴드 타격을 위한 슈팅 매커니즘의 토대를 다집니다.

## 2. 핵심 구현 내용 및 세부 설계
- **원근 투영 공식 적용**: 3차원의 깊이 좌표 $Z$값에 따라 중앙점($X_c, Y_c$)을 기준으로 스케일링을 수행하여 멀리 있는 물체는 좁고 가까이 있는 물체는 넓게 퍼지도록 좌표를 변환하는 연산을 수행했습니다.
- **입체 터널 그리드 구현**: 전진 속도 프레임에 맞춰 터널 라인들을 배치하여 터널 안을 전진하는 느낌을 렌더링했습니다.
- **조준 Reticle**: 화면의 마우스 X, Y 위치를 실시간 추적하여 크로스헤어 정렬 및 Aiming 피드백 효과를 구성했습니다.

## 3. AI 에이전트 협업 & 프롬프트 예시
- **프롬프트**: "Love2D 환경에서 3D 느낌이 나는 2.5D 터널 그리드를 그리고 싶어. 깊이 Z가 10.0부터 0.0까지 다가오도록 원근 투영 공식(Perspective Projection)을 작성하고 그리드로 원들을 그리는 코드를 작성해줘."
- **협업 내용**: 에이전트는 3차원 투사 공식의 수학적 근거를 바탕으로 `project(x, y, z)` 함수를 작성했고, Z값이 0 이하가 될 때 발생하는 `Division by Zero (제로 나눗셈)` 에러 방지를 위해 하한 임계값(`0.05`)을 추가 설계하여 충돌을 사전에 완벽 차단했습니다.

## 4. 디버깅 및 검증 과정
- **문제점**: 화면 중앙점 좌표가 프레임마다 흔들리거나 깊이 연산이 어색하게 다가오던 이슈가 있었습니다.
- **해결 및 검증**: 화면 너비와 높이의 절반 값을 고정 중심(`center_x = 640`, `center_y = 360`)으로 바인딩하고, $Z$축 등속 전진 공식에 델타타임(`dt`)을 정밀하게 연동하여 프레임 변화에 영향받지 않는 선형 입체 전진 운동을 수식으로 완벽히 보정하여 검증했습니다.

## 5. 핵심 소스코드 블록 및 설명 (`grid_renderer.lua`)
```lua
-- 3D 공간 좌표 (x, y, z)를 원근 투상 공식(Perspective Projection)을 통해 2D 화면 좌표로 변환
function grid_renderer.project(x, y, z, zoom_override)
    local zoom = zoom_override or (400 + 40 * grid_renderer.beat_pulse)
    z = z or 10.0
    if z <= 0.05 then z = 0.05 end -- 제로 나눗셈 에러 발생 방지 예외처리
    
    -- 원근법 적용: Z(깊이)가 클수록 중심축으로 가깝게 모여 렌더링됨
    local sx = center_x + (x * zoom / z)
    local sy = center_y + (y * zoom / z)
    return sx, sy
end
```
