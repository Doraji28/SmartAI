# [Day 6 Worklog] 메인 타이틀 화면 설계 및 곡별 일러스트 배경 매핑

## 1. 개발 목표
- 게임의 전체적인 조형적 일체감을 높이고 첫인상을 끌어올리기 위한 시작용 메인 타이틀 화면을 기획 및 구현합니다.
- 각 스테이지 및 곡의 개성을 나타낼 수 있는 개별 앨범 아트 일러스트를 오디오 로딩과 연동하여 배경으로 스케일링하여 출력합니다.

## 2. 핵심 구현 내용 및 세부 설계
- **글리치 메인 타이틀**: "SOULROCK - 최고의 음악들과 함께 즐기는 리듬게임" 타이틀 로고를 Magenta/Cyan 오프셋 글로우 및 주기적 글리치 연출과 함께 메인 화면에 배치했습니다.
- **이미지 자동 크기 맞춤 (Auto-Scaling)**: 임의 해상도의 일러스트 이미지를 1280x720 해상도 창 크기에 빈틈없이 채우는 종횡비 유지 스케일링 연산 및 오퍼시티 페이딩을 적용하여 렌더링을 고도화했습니다.

## 3. AI 에이전트 협업 & 프롬프트 예시
- **프롬프트**: "메인 화면 로고가 평범하게 그냥 나오니까 정적인 느낌이 강해. Magenta와 Cyan 색상 오버레이 글씨를 2픽셀 좌우 오프셋을 줘서 그리고 시간 사인함수에 맞춰 오파시티가 미세하게 진동하는 네온 글리치 효과를 타이틀에 구현해줘."
- **협업 내용**: 에이전트는 로고 가독성을 유지하면서 입체적인 사이버펑크 네온 색조 조합을 적용할 수 있도록 로고를 세 차례 다르게 중첩 그리는 멀티 드로잉 로직을 완성했습니다.

## 4. 디버깅 및 검증 과정
- **문제점**: 다양한 규격의 곡별 일러스트를 화면에 그릴 때, 특정 해상도 이미지들은 늘어나 깨지거나 혹은 바깥 영역이 잘려 렌더링되는 부적합한 연출을 유발했습니다.
- **해결 및 검증**: 이미지의 크기를 가져오는 `getDimensions()` 함수와 화면비의 스케일 계수 `math.max(screen_w / img_w, screen_h / img_h)` 연산 조합을 구축하여 종횡비를 깨지 않으면서 채워 렌더링되도록 스케일 공식을 수정하여 검증했습니다.

## 5. 핵심 소스코드 블록 및 설명 (`main.lua` 발췌)
```lua
-- [6일차 구현] 종횡비를 보존하며 화면을 꽉 채우는 일러스트 배경 그리기 공식
local function draw_bg_image(img, opacity)
    if not img then return end
    local screen_w, screen_h = 1280, 720
    local img_w, img_h = img:getDimensions()
    
    -- 화면을 다 채우기 위해 너비 스케일과 높이 스케일 중 큰 비율을 선택
    local scale = math.max(screen_w / img_w, screen_h / img_h)
    
    -- 가로세로 중앙 정렬을 위해 오프셋 보정 수행
    local tx = (screen_w - img_w * scale) / 2
    local ty = (screen_h - img_h * scale) / 2
    
    love.graphics.setColor(1, 1, 1, opacity)
    love.graphics.draw(img, tx, ty, 0, scale, scale)
end
```
