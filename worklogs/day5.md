# [Day 5 Worklog] 곡 목록 확장 및 Lerp 기반 스무스 스크롤 메뉴 구현

## 1. 개발 목표
- 11곡으로 구성된 다채로운 음악 라인업 카탈로그 데이터를 구축합니다.
- 많은 곡이 추가되어 단일 화면에 들어오지 않는 문제를 해결하고, 부드럽게 감속하며 상하 이동하는 마우스 휠 기반의 OSU! 스타일 스무스 슬라이딩 카탈로그 스크롤 메뉴를 만듭니다.

## 2. 핵심 구현 내용 및 세부 설계
- **카탈로그 확장**: 11개의 수려한 오디오 파일 리스트 메타데이터(BPM, 총 비트 수, 난이도 등) 구조를 마련했습니다.
- **스무스 선형 보간(Lerp) 스크롤**: 마우스 휠 및 키보드 입력 시 스크롤 목표 좌표(`target_scroll_y`)를 증감시키고, 실제 스크롤 값(`scroll_y`)은 선형 보간 공식을 이용해 감속하며 쫓아가도록 설계하여 고급 아케이드 감각을 재현했습니다.

## 3. AI 에이전트 협업 & 프롬프트 예시
- **프롬프트**: "휠 스크롤을 굴릴 때 곡 선택 카드가 툭툭 끊겨서 이동해. 부드럽게 미끄러지듯 감속해서 정지하는 스무스 스크롤 효과(Lerp) 연산 식을 매 프레임 업데이트 루프 안에 구현해줘."
- **협업 내용**: 에이전트는 프레임률 독립적(Frame-rate Independent) 감속 비례 계수인 `scroll_y = scroll_y + (target_scroll_y - scroll_y) * 12.0 * dt` 수식을 제안하여 프레임 변화에 구애받지 않고 일관적으로 작동하는 스무스 보간 수식을 완성했습니다.

## 4. 디버깅 및 검증 과정
- **문제점**: 마우스 휠을 한 번만 돌려도 곡 선택 스크롤 한계 범위를 아예 넘어가서 목록이 아예 공백 화면으로 스크롤되어 사라져 버리는 현상이 보고되었습니다.
- **해결 및 검증**: 카탈로그의 최소/최대 좌표 범위를 계산하고, 선택한 곡의 고유 인덱스가 화면 정중앙에 맞춰지도록 정렬 오프셋을 역산하여 스크롤 한계를 클램프(`Clamp`) 함수로 제어해 완벽히 해결했습니다.

## 5. 핵심 소스코드 블록 및 설명 (`ui_overlay.lua` 발췌)
```lua
-- [5일차 구현] 목표 스크롤 값으로 부드럽게 감속 접근하는 선형 보간(Lerp) 스무스 스크롤
function ui_overlay.update(dt)
    if ui_overlay.rating_timer > 0 then
        ui_overlay.rating_timer = ui_overlay.rating_timer - dt
        ui_overlay.rating_scale = math.max(1.0, ui_overlay.rating_scale - 3.5 * dt)
    end
    
    -- 12.0 계수와 프레임 델타 dt를 곱해 지수적 감속을 통해 부드럽게 목록을 정렬시킴
    ui_overlay.scroll_y = ui_overlay.scroll_y + (ui_overlay.target_scroll_y - ui_overlay.scroll_y) * 12.0 * dt
end
```
